# 小鶴設定工具與小狼毫繁體配置

以 Windows 小狼毫、雾凇拼音與標準小鶴雙拼為基礎，提供原生繁體中文設定介面。這是獨立社群工具，非 Rime 或雾凇官方產品。

公開版本沒有作者的個人詞彙、學習記憶、使用記錄、裝置識別或外觀偏好。個人詞庫及捷徑檔預設空白。

## 下載與安裝

1. 從 [小狼毫官方 Releases](https://github.com/rime/weasel/releases) 安裝 Windows 小狼毫。測試版本為 Weasel 0.17.4、librime 1.13.1。
2. 在本專案 Releases 下載 Windows x64 完整套件，解壓縮。
3. 在資料夾中執行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1`。這只影響該次程序，不改永久執行原則。不需要管理員權限。
4. 用 Windows 輸入法切換選擇小狼毫；開始選單開啟「小鶴設定工具」。

安裝器預設使用 `%APPDATA%\RimeFlypy`，拒絕覆蓋非空白目的地，保留既有 Rime 資料。若只有原始碼，安裝時會從官方 GitHub 下載鎖定版本的雾凇；GUI 需先自行建置。`Install.ps1 -UserDir <新資料夾> -PrepareOnly` 只建立配置，不切換正式輸入法。

## 功能

- 「外觀與按鍵」：字體、字級、排列、配色、間距、圓角、左右 Shift 與即時預覽；左側支援滾輪，移到數值或選單上捲動不會改值。
- 「全部設定」：依用途分類、中文名稱與說明、搜尋、保留原始識別碼，變更使用 `.custom.yaml`。
- 「我的詞彙表」：中文、英文、混輸、個人詞及匯出的學習記憶統一搜尋；來源與是否啟用分開標示。索引包含未啟用詞庫，不等於全部參與候選。
- 「備份與還原」：設定及詞彙規則的備份；不回退學習資料庫。
- 「快捷鍵對照表」：從目前配置及待儲存調整產生，可分類、搜尋、選取查看完整說明。

預覽使用一般固定詞彙；陰影、字體平滑及靠近螢幕邊緣時的定位以實際小狼毫為準。按「儲存並重新部署」才套用。設定副本不能透過 GUI 部署，以免誤改正式輸入法。

## 繁體與原詞

預設使用 OpenCC `s2tw`：轉繁體與台灣字形，保留原詞。`ruan jian` 輸出「軟件」、`xiang mu` 輸出「項目」，不強制替換成「軟體」「專案」。繁簡歧義仍按詞判斷，例如「头发→頭髮」。`s2twp` 地區用語替換保留為明確自選選項。

預設保留常用詞庫、長詞組句、詞頻學習、英文／中英混輸、Emoji、日期時間、農曆、中文數字、網址及 Email、拆字反查；大型騰訊詞庫及大字表不預設啟用。英文候選保持較低優先度。

2.2.1 起，R＋數字的繁體大寫採「參」，候選說明使用繁體中文；修正模組獨立於上游 Lua，更新時保留。

## 快速學習與不同寫法

2.2.3 起，手動改選的完整字詞在下次相同完整小鶴編碼、相同繁簡模式中優先。最近一次手動改選者優先，其餘已記住的詞按選用次數排列，同分保留引擎順序；明確固定首位及隱藏規則仍優先。原生 Rime 詞頻學習繼續運作。這是參考 Apple 公開選字範例的自訂行為，不是 Apple 原版演算法。

個人詞保留輸入的繁體字形；布／佈、台／臺、里／裡等可並存。`flypy_learning.tsv` 在每次符合條件的上屏後追加保存，不因久未使用而清除；重新部署或更新不刪除。它包含私人輸入記憶，不可公開上傳。不同字形的隱藏、固定首位分開管理；修改一個詞不必把其他寫法一起替換。

自動保存採可解釋的近似分界：同一次組字內選字上屏、純中文字、1～12 字、每字有完整兩鍵小鶴編碼。沒有「詞義正確」或內建詞庫白名單限制，也支援組字過程中逐段選出的自造詞；日期、數字、網址及帶標點的句子不加入。**純中文短句仍可能被記成詞，分開多次上屏的字不會猜測合併**。超長詞可從「＋ 中文詞」加入；「全部設定 → 詞庫與排序 → 自動保存的最長字數」可調整自動保存長度。

在「我的詞彙表」搜尋可直接讀入最新快速學習紀錄；來源為 `flypy_learning.tsv`，編碼欄是小鶴鍵位。可編輯、隱藏或固定首位；隱藏永久有效，取消規則可恢復。原生 Rime 學習資料仍以「更新詞庫與學習記憶」匯出快照。完整備份須包含此 TSV；介面的設定還原不回退它，避免遺失之後學到的詞。

## 個人詞與備份

在詞彙表新增中文詞並填完整拼音；英文與混合名稱放在捷徑。內建詞可隱藏、替換顯示或固定首位；手填的繁體字形會原樣保留；固定首位只調整完整輸入的前 256 個候選，不直接刪改上游詞庫。學習記憶需按「更新詞庫與學習記憶」匯出才刷新，不是逐鍵即時快照。匯出時短暫暫停輸入法。

`Maintain.ps1 -Action Backup` 建立完整備份，`-Action Sync` 匯出 Rime 詞頻同步資料，`-Action Deploy` 重新部署。`-Action UpdateIce` 更新到套件鎖定的雾凇版本，先備份並保留個人 patch／詞庫／學習資料。更新到新上游版本須使用驗證過的新發行套件。

更新雾凇前先備份；保留 `*.custom.yaml`、`flypy_personal.dict.yaml`、`flypy_phrases.txt`、個人詞彙規則、`*.userdb`、`installation.yaml`。優先用小狼毫的「用戶資料同步」產生詞頻快照，再備份整個資料夾。雲端同步開啟中的資料庫不等同於一致性備份，勿讓多台電腦同時共用同一份活動資料庫；多裝置請使用各自的使用者目錄與 Rime 同步。

新電腦安裝後不要直接沿用其他裝置的 `installation.yaml`。同步資料可能包含輸入記憶，不要上傳到公開 Git repository。

## 原始碼、建置與驗證

Python 3.13，Tkinter/ttk；依賴版本已鎖定。建立虛擬環境後執行 `Build.ps1 -Python <虛擬環境的python.exe>`，輸出位於 `dist`。測試使用程式生成的空白範例，沒有本機個人路徑或私人詞庫依賴。

`upstream.json` 記錄雾凇的固定來源版本，安裝器不會默默改用未驗證的最新分支。要升級請更新上游鎖定版本並重新測試英文／反查雙拼規則，再發布版本。`--user-dir` 僅供隔離設定測試；原生引擎測試須直接指定測試目錄，不可對副本執行正式部署。

## 台灣補充詞庫與逐段組詞（2.2.4）

加入獨立的 `flypy_taiwan.dict.yaml`，來自 [小麥注音 McBopomofo](https://github.com/openvanilla/McBopomofo) 固定版本的字音、字詞與語料頻率資料。保留上游注音對應的完整拼音，不依讀音猜測產生詞庫；常用 Big5 單字、實際語料使用單字及可對應讀音的詞彙經篩選、去重後共有 156,216 筆字音／詞音資料（154,031 個不同字形／詞形）。這是補充資料總數，與雾凇已有詞存在重疊，不代表全為新增的不重複詞。

台灣原詞形及對應繁體慣用字形可並存，例如台灣／臺灣、分布／分佈；沒有強迫替換地區用語。詞庫來源在「我的詞彙表」標為「台灣詞庫」，可搜尋、加入個人詞、隱藏、替換或固定首位。個人規則優先，不直接改上游檔案。

`tdwj` 可選台灣、臺灣，也能先選台再選灣；個人新增的其他單字、短詞也會在較長輸入中保留供組詞，正確消耗已選的前半段。自造詞於同一次組字完成後依既有規則記住。最多讓兩個個人前綴候選保留在前頁，不把所有短字都壓到完整詞之前；手動改選完整詞仍會即時影響下次排序。

資料鎖定與 SHA256 見 `taiwan-upstream.json`，授權全文見 `licenses/McBopomofo-MIT.txt`。建置時 `build_taiwan_dictionary.py` 下載並驗證固定來源，再產生詞庫；生成檔隨執行檔、Release 安裝包發布。原始碼 checkout 請先建置，單獨執行安裝器前也可先執行此產生程式。公開原始碼不收錄任何本機個人字詞或學習資料。

2.2.5 補上 Email、URL、數字與標點的組詞範圍檢查，避免個人拼音前綴誤插入這些候選。

2.2.6 起，「我的詞彙表」底部可直接輸入頁碼，按 Enter 或「前往」跳轉；總頁數依目前搜尋／分類更新。

2.2.7 起，翻頁後會回到第一筆。表格右下角的小圖示可展開檢視，再點一次或按 Esc 還原；操作及翻頁控制仍可用，切換分頁自動還原。視窗原本的位置和大小也會還原。

英文預設只列完整匹配，不補上一長串延伸詞。例如輸入 `github` 顯示 `github`、`GitHub`；原本就是 `GitHub` 時不重複列出。中文候選順序、自訂捷徑與完整名稱仍保留。若需要英文長詞自動補全，可在全部設定的詞庫與排序分類開啟英文／中英混輸補全；「英文候選先保留原始大小寫」亦可自行切換。


## 輸入與登入效能（2.2.8）

一般輸入逐筆產生候選；需要合併個人詞或學習詞時只預讀一頁，保留最新改選、詞頻及字形並存。字形保護改讀小型 `flypy_taiwan_variants.txt`，與補充詞庫由同一份固定來源產生。隱藏／替換規則在沒有固定首位規則時不預讀 256 筆；明確設定固定首位仍保留原有搜尋範圍。

若登入後小狼毫遲遲未出現，可選用 `Enable-FastStartup.ps1` 建立目前使用者的登入啟動工作。先在工作管理員停用原有 WeaselServer 啟動項；腳本會檢查此條件，避免官方啟動項與工作排程重複啟動。腳本不需系統管理員、不修改全系統啟動延遲或永久執行原則，也不會當場重啟輸入法。不要直接重複執行 WeaselServer.exe，因官方程式會關閉既有服務再啟動。

要取消此選用工作，可在工作排程器停用 `FlypySettings-WeaselStartup`，再於工作管理員啟用原有 WeaselServer 啟動項。輸入法資料仍保存在原來的使用者資料夾。


### 登入啟動器（2.2.10）

`Enable-FastStartup.ps1` 現在只用於安裝／更新工作。工作執行時直接使用約數 KB 的 `WeaselStartup.exe`，不再先啟動 PowerShell。發行包附啟動器及同版 `WeaselStartup.cs`；原始碼建置使用 Windows 內建 .NET Framework 編譯器。啟動器檢查同一工作階段的既有服務，絕不主動重啟它；`--check` 只作唯讀就緒檢查，不啟動服務。

本機 `%USERPROFILE%\.flypy-settings\startup-status.log` 只記錄啟動時間、耗時和結果，不含打字內容；最多約 32 KB 後重新記錄。舊工作定義備份也只留在本機。移除或停用方式與前述相同。排程採目前使用者、一般權限、正常優先序與可用時補執行，不依賴 OneDrive 程式先啟動；仍以 Windows 登錄的 Rime 資料夾為準。登入後實際可用時間需實機驗證。

啟動器安裝於使用者資料夾的 `.flypy-settings` 子資料夾，以避免封裝桌面應用程式對 AppData 的檔案重新導向；工作命令、啟動器與狀態檔使用同一個實際位置。

2.2.11 起，每個完成詞仍立即寫入學習紀錄；使用一次無緩衝寫入並重用連線，避免每次選字都重複開關檔案。句末標點、英文等不符合詞彙學習條件的上屏會關閉連線，最後輸入工作階段結束／重新部署時也會關閉。不是延後數秒或退出時才保存；活動中讀取詞彙表亦可看到已寫入的紀錄。雲端備份仍應使用一致性快照，活動資料庫不宜讓多台電腦同時寫入。

啟動器也會以不建立輸入工作階段的 IPC Echo 量測服務回應，最長等候 90 秒後退出；另以背景唯讀方式檢查設定檔是否可讀。不發送按鍵、不變更焦點或組字，紀錄僅留在本機。`--probe` 可單獨執行這項有限時的唯讀檢查；服務程序存在不等於已可輸入。

2.2.12 修正直接綁在同一英文編碼的延伸名稱：精簡模式輸入 `windows` 只列 `windows`／`Windows`，不再附加 Windows 各版本；輸入 `windowsxp` 仍可取得 `Windows XP`。同樣規則套用其他英文名稱，中文候選與不以原編碼開頭的縮寫捷徑照常保留。啟用英文補全時仍可列出延伸名稱。

## 輸入統計（2.2.13）

「輸入統計」分頁沿用目前外觀，提供常用字詞／詞內常用字排行、累計中文選用與字數、字詞種類、平均詞長、最長學習詞、每日選用／字數／首次學習與改選比例，以及活躍中文上屏速度估算。可放大表格；只有切入分頁或按更新時才在背景讀取。

原有 `flypy_learning.tsv` 的累計次數可直接納入，不把每次保存都加總。舊資料沒有時間資訊，不能還原過去每日紀錄或速度。更新後只在原有中文完整組字保存時，於同一次無緩衝寫入附加不含文字的 `#stats-v1` 註解列；五欄學習格式、詞頻及原有讀取器保持相容。不新增全域／逐鍵監聽或逐鍵檔案操作。

範圍是小鶴原本會保存的 1～12 字中文完整組字；不是全電腦輸入量，英文、貼上或完整長句不計入。速度只取相隔至多 30 秒的連續上屏片段，每段至少 10 秒且五次後續上屏，以有效總字數／總秒數計算；段首第一詞不列入速度。暫停、時鐘倒退、非學習輸入邊界會切開樣本。秒級時間不適合短時打字競速，介面會標為估算，沒有樣本時不編造數字。

統計留在原有 Rime 資料夾，跟隨使用者既有備份；不傳送到分析服務或本專案。公開配置與安裝包不包含任何人的統計、學習紀錄或使用歷史。
